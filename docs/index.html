意見マンダラート

意見を 8 つずつに割り、1 マスが意見 1 枚になるまで繰り返した木を、中心＋周り 8 マスで降りていく。9×9 にすると周り 8 マスの中身も同時に見える。最下層から元の提案に飛べる。

付箋ズーム

広聴AI の 2 次元配置の上に意見を付箋で置く。引いた状態でも各まとまりの表札が付箋で読め、寄るほど意見の付箋が増え、最後は全意見が付箋になる。付箋の位置と出始める拡大率は事前に決めてあるので、拡大しても入れ替わらない。

階層リスト（ツリー表示）

広聴AI の上位・下位のクラスタを上から展開して、最下層で個々の意見と元の提案まで辿る。検索つき。本体の公開ビューアにも「全部読む」詳細モードとして入っている（kouchou-ai PR #1166）。ここにあるのは同じ見せ方の単体版。
状態：本体に入った · 最終確認日：2026-11-07

対立軸ビュー（DivCon）

tokoroten の DivCon を広聴AI のまとまりに当てたもの。賛否の割れそうなまとまり（エネルギー・家族・移民・皇位継承）ごとに LLM が対立軸を見つけ、各意見を軸の上で 1〜6 に採点して、左右の欄に強い立場から並べる。LLM が挙げた「合意できそうな点」と「根本的に対立する点」も出す。
状態：実験 · 本体に入れる候補か：未判断 · 日本語のみ · 最終確認日：2026-11-08

賛否スライダー

tokoroten のセンチメント次元の付与（sentiment-weighted UMAP）。意見ごとの賛否スコア（広聴AI の opinion_stance と同じプロンプト）に重みを掛けて埋め込みに足し、重みのスライダーを動かすと、同じ話題の賛成と反対が離れていく。賛否の分かれ方と、話題の近さがどれだけ崩れたかも数値で出す。
